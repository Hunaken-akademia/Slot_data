# SLOT DATA / エスパス赤坂見附

エスパス日拓 赤坂見附駅前店の2026-05-25〜2026-08-18スロットデータ閲覧サイトです。

- 86日分、25,886行
- 日付ごとに台番号と機種名を保持
- 直近の取得分（08-19以降）は差枚がプラス/マイナスとも正常に取得できていることを確認できるまで表示範囲から除外しています。今後の毎日更新で正常なデータが確認でき次第、表示期間は自動的に伸びていきます（最終的に直近1年分を目標）
- 掲載元が差枚を未確定のまま返す台は「―」（データなし）として表示し、平均や勝率の集計からも除外しています（0として扱いません）
- みとや水道橋・稲毛駅前新館の2店舗は、取得データにマイナス差枚が一件も含まれておらず取得元データの信頼性が確認できないため、正常なデータが取れるまで一時的に非表示にしています
- 公開差枚結果の集計であり、設定を断定するものではありません
