# SLOT DATA

店舗別スロットデータ閲覧サイトです。現在の対象店舗はエスパス日拓 赤坂見附駅前店（2026-05-25〜2026-08-18）、店舗タブは掲載店舗が2つ以上になった時だけ表示されます。

- 86日分、25,886行
- 日付ごとに台番号と機種名を保持
- 掲載元が差枚を未確定のまま返す台は「―」（データなし）として表示し、平均や勝率の集計からも除外しています（0として扱いません）
- `scripts/build-data.mjs` は日付ごとに「非nullの差枚のうちマイナスが1件もない」かを自動判定し、サンプル数が十分（`minRows`の30%以上）なのに1件もマイナスが無い日は"取得元が確定済みのマイナス結果を「―」に戻して隠している"日とみなして集計・表示から自動的に除外します（`summary.json`の`unreliableDates`）。表示期間（`period`）はこの判定を通過した日だけの範囲になり、毎日の更新のたびに自動で再計算されます
- 2026-08-26時点の調査で、この「確定済みのはずのマイナス差枚を後から「―」に戻す」現象はみんレポ（min-repo.com）側の仕様であり、赤坂見附に限らずサイト上の無関係な他店舗十数件の最新レポートでも同時に確認されました。赤坂見附の2026-05-25〜08-18が「クリーンな期間」として残っているのは、日次取得（毎日00:10 JST）がこの現象が始まる前にその期間のデータを捕捉できていたためです。08-19以降分・および過去の日付を今から再取得してもマイナスは「―」に戻っており、取得済みアーカイブ（このリポジトリのJSON）を書き換えない限り失われます
- みとや水道橋・稲毛駅前新館・やすだ清水町店の3店舗は、取得済み全期間（赤坂見附と同じ2026-05-25〜）を通じてマイナス差枚が1件も確定して取得できておらず、上記の自動判定により全日が除外対象になるため店舗タブから除外しています（データファイル自体は`public/data/stores/`配下に保持、収集は継続中）。スロレポ（slorepo.com）・DMMぱちタウン内のP'sCUBE（pscube.jp）に同種のページがありますがいずれもCloudflareのボット対策で保護されており、みんパチ（minpachi.com）はみんレポへのリンクとコメント欄のみで独自の差枚データを持たず、サイトセブン（site777.jp）は自動アクセスがブロックされ対象ホールに含まれているかも未確認のため、現時点で乗り換え可能な代替データソースは見つかっていません
- 店舗を追加する場合は`scripts/stores.mjs`にエントリを、`.github/workflows/daily-slot-data.yml`のmatrixにslugを追加してください。`public/data/stores.json`に載せると店舗タブに表示されますが、上記の自動判定で対象店舗の`summary.json`が0日（`days:0`）のままなら「データ収集中」の空表示になります（クラッシュはしません）。収集を続けて信頼できる日が確認できるようになれば、次回の自動更新から表示期間が自動的に始まります
- 公開差枚結果の集計であり、設定を断定するものではありません
